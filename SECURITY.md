# Security

Report a vulnerability in this plugin, its launcher, or the Jannoo app to <security@jannoo.app>.
Do not open a public issue for it. You will get an acknowledgement, and a fix or a reasoned answer,
before anything is disclosed.

The launcher runs only a Jannoo helper whose signature is anchored to Apple's certificate authority
for team `8A6D992J4P` and which answers the `mcp` verb. If you find a way past that check, that is a
report we want.
